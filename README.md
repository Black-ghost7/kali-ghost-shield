# Ghost Shield (Python)

سكربت Python لأتمتة تغيير عقدة الخروج في شبكة Tor، مع مفتاح قطع تلقائي (Kill Switch) عبر iptables، ومنع تسريب DNS وIPv6، ونظام نسخ احتياطي/استعادة تلقائي لإعدادات النظام.

## الملفات

- `ghost-shield.py` — السكربت التنفيذي.
- `README.md` — هذا الملف (الشرح والتعليمات فقط).

## المتطلبات

- Kali Linux (أو أي توزيعة تحتوي `iptables` و`tor` و`torsocks`)
- Python 3
- صلاحيات `root` أو `sudo`
- الحزم: `tor`, `torsocks`, `iptables`

## تثبيت المشروع من GitHub

```bash
git clone https://github.com/Black-ghost7/kali-ghost-shield.git
cd kali-ghost-shield
chmod +x ghost-shield.py
```

## قبل التشغيل

افحص السكربت أولًا:

```bash
python3 -m py_compile ghost-shield.py
```

ثم اقرأه:

```bash
less ghost-shield.py
```

## التشغيل

```bash
sudo python3 ghost-shield.py
```

يقوم السكربت بـ:
1. تحديد بلدك الحقيقي لاختيار دول خروج مجاورة له.
2. حفظ نسخة احتياطية من `resolv.conf` و`torrc` وحالة IPv6 وقواعد `iptables` الحالية (قبل أي تعديل).
3. تفعيل Kill Switch وتعطيل IPv6 وتوجيه DNS بأمان.
4. تشغيل Tor وتغيير موقع الخروج دوريًا كل 60 ثانية (قابل للتعديل داخل الكود عبر `CHANGE_INTERVAL`).
5. مراقبة الاتصال كل 15 ثانية وعرض إحصائيات حية.

## الإيقاف والاستعادة التلقائية

اضغط `Ctrl+C` لإيقاف السكربت. عند الإيقاف:

- تُستعاد `resolv.conf` و`torrc` وحالة IPv6 وقواعد `iptables` تمامًا كما كانت قبل التشغيل.
- يُحذف مجلد النسخ الاحتياطي المؤقت بالكامل، فلا يبقى له أي أثر.
- يُحفظ ملف تقرير واحد فقط باسم `ghost_report.txt` في مجلدك الشخصي، يحتوي إحصائيات الجلسة وسجل المواقع المستخدمة.
- يسألك السكربت مباشرة إن كنت تريد حذف هذا الملف أو الاحتفاظ به.

## ملاحظات مهمة

- السكربت يعدّل إعدادات النظام والشبكة (`iptables`, `/etc/resolv.conf`, `/etc/tor/torrc`, IPv6) بشكل فعلي أثناء التشغيل.
- راجع الكود قبل تشغيله بصلاحيات `root`، خصوصًا إن كنت تستخدم الجهاز لأغراض أخرى بالتوازي.
- لا تعتبر Tor أو تغيير موقع الخروج ضمانًا كاملاً لعدم إمكانية التتبع.
- هذا المشروع مخصص لإدارة وحماية جهازك وبيئتك التي تملكها أو لديك تصريح بإدارتها.
