# 👻 Ghost Shield v2.1

أداة أتمتة وتخفي كاملة لنظام **Kali Linux** (سواء كان يعمل كنظام أساسي، عبر Live USB، أو بيئة وهمية).

تقوم الأداة بتغيير موقع خروج شبكة **Tor** تلقائياً، مع تغيير الـ **MAC Address** واسم الجهاز (**Hostname**)، وتفعيل **Kill Switch** لحماية الاتصال من التسريب.

---

## 📋 المميزات الأساسية

- 🌍 **تغيير تلقائي لعقد خروج Tor:** اختيار دول قريبة جغرافياً لتقليل البطء وزيادة السرعة.
- 🔒 **تغيير الـ MAC Address تلقائياً:** التعرف التلقائي على واجهة الشبكة النشطة (`wlan0` أو `eth0`) وتغيير عنوانها.
- 🎭 **تغيير اسم الجهاز (Hostname):** اختيار اسم عشوائي للهوية لمنع كشف نوع أو اسم حاسوبك في سجلات الشبكة.
- 🛡️ **جدار ناري لحظر التسريب (Kill Switch):** حظر أي حركة مرور خارج نطاق Tor عبر `iptables`.
- 🔐 **منع تسريبات DNS و IPv6:** تعطيل IPv6 وتوجيه طلبات DNS محلياً وأمان.
- 🧹 **استعادة وأمان عند الخروج:** إرجاع كافة الإعدادات الأصلية للنظام ومسح السجلات المؤقتة فور الضغط على `Ctrl+C`.

---

## 🛠️ المتطلبات الأساسية

قبل تشغيل الأداة لأول مرة، تأكد من تثبيت الحزم والأدوات التالية عبر الـ Terminal:

```bash
sudo apt update && sudo apt install -y tor torsocks iptables curl python3 e2fsprogs macchanger
```

---

## 🚀 طريقة التشغيل

1. إعطاء صلاحية التنفيذ للسكربت:

```bash
chmod +x ghost-shield.py
```

2. تشغيل السكربت بصلاحيات المسؤول (Root):

```bash
sudo python3 ghost-shield.py
```

3. إيقاف التشغيل والأمان:

اضغط على `Ctrl + C` في أي وقت لإيقاف الأداة. ستقوم الأداة تلقائياً بـ:

- استعادة الـ Hostname والـ MAC Address الأصلي.
- استعادة قواعد الـ iptables و DNS.
- تنظيف السجلات المؤقتة وحذف الملفات المؤقتة بـ Shred.
